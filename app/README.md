# 城市自由行 App · 开发版本

移动端 Web 演示版。用替代资源把 P0 闭环跑通：**探索 → 创建 → 生成 → 调整 → 今天 → 保存**。

设计稿见 `../design/城市自由行-App设计稿-v1.html`，产品规划见 `../output/20261103-travelapp/stage3/`。

---

## 运行

```bash
cd app
npm install
npm run dev        # http://127.0.0.1:5178
```

浏览器打开后按 F12 切到手机视图（430 × 900）体验最佳。构建：`npm run build`。

## 排程逻辑

四步，全部在本地完成，无后端：

1. **分天**：按"平均分 × 规模系数"给片区排序，依次分配给每天；有预约的那天，片区锁定为预约地点所在片区。
2. **切段**：把一天按预约切成若干时间窗，每段独立填充。
3. **填充**：每个窗口内按评分取最优候选。评分 = 兴趣命中 0.35 + 评分 0.15 + 时段适配 0.15 + 预算 0.10 + 距离 0.12 + 必去加权 0.25。逐项校验停留时长、最晚入场、闭馆日、相邻交通上限、预算上限。
4. **重算**：用户替换或跳过某一项后，`recomputeDay` 从当天第一项开始重排所有后续时间与交通。

节假日、跨天预约、多预约并行等复杂情况尚未覆盖。

## 已知限制

- 交通耗时按直线距离估算（步行 75m/min、地铁 320m/min+14、公交 260m/min+18），界面标"估算"。
- 收藏与行程存在浏览器里，清缓存即丢。
- 分享链接是 `#/s/<token>` 形式，快照存在本机 localStorage，跨设备打开会失效；正式版需服务端短链。
- 交通耗时仍是估算（直线距离 × 1.35 路网系数）。天地图路径规划接口只支持驾车，不提供步行 / 公交，对本产品参考价值有限，暂未接入。
- 天地图 key 有调用配额，短时高频请求可能被临时禁用；瓦片失败时地图会空白并给出提示。
- 地图是 SVG 示意图，按经纬度相对位置绘制，不能导航。
- 兴趣标签点击第二下本应加强权重，当前只做选中/取消。

## 地图方案

用 **MapLibre GL JS 6.x**（BSD-3，无 key，可商用）作为渲染引擎，但底图是自己构造的 GeoJSON：

- 片区轮廓（不规则多边形）、一环 / 二环路、主干道、水系
- 点位用 HTML Marker（不依赖 glyphs 字体，样式完全可控）
- 路线用 line layer，跟随点位偏移重算端点

这样做的原因：MapLibre 只是渲染器，底图数据才是合规与成本的关键。当前底图零第三方依赖，可离线、可截图、无授权风险。

已内置天地图接入，在「我的 → 地图底图」填入 tk 即可切换，无需改代码。

### 接天地图

> 本项目已在 `.env.local` 配好 key，默认走天地图。该文件不入库；换 key 时改这里，或在「我的」里直接填。
> key 失效时地图会变空白，切回「示意图」即可正常使用其余功能。

1. 打开 `console.tianditu.gov.cn` 注册并完成实名认证
2. 创建应用，类型选「浏览器端」
3. Referer 白名单填 `127.0.0.1` 与 `localhost`（上线后补正式域名）
4. 复制 tk，粘贴到「我的 → 地图底图 → 天地图 key」，点「天地图」

瓦片地址（`src/core/mapConfig.ts`）：

```
https://t0.tianditu.gov.cn/{vec|cva}_w/wmts
  ?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0
  &LAYER={vec|cva}&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles
  &TILECOL={x}&TILEROW={y}&TILEMATRIX={z}&tk=<你的 tk>
```

- `vec_w` 是底图，`cva_w` 是地名注记，两层叠加
- 天地图用 CGCS2000，与 WGS84 差异在厘米级，本项目数据可直接叠加，**不需要** GCJ-02 那套偏移转换
- tk 是前端明文，靠 Referer 白名单保护，不要提交到公开仓库
- 上线时需在地图页标注来源与审图号（天地图官网可查），当前仅在右下角标了「底图 © 天地图」

如果切过去地图空白，先查白名单：`127.0.0.1` 与 `localhost` 是两个不同的 Referer，建议都加上。

### 其他底图

| 底图 | 合规 | 接入方式 |
| --- | --- | --- |
| 天地图 | 有审图号，需申请 key | `raster` source，WMTS 瓦片 |
| 高德 / 腾讯 | 需商用授权 | 建议直接用官方 JS SDK，而非 MapLibre |
| OSM 系（MapTiler 等） | 境内边界表达不合规 | 仅限本地技术验证，不可上线 |

**坐标系注意**：高德 / 腾讯用 GCJ-02，本项目数据是 WGS84，直接叠加会偏 300—500 米；天地图用 CGCS2000，与 WGS84 差异可忽略。

Vite 下接 MapLibre 需要两行配置（已在 `vite.config.ts`）：

```ts
worker: { format: 'es' },
optimizeDeps: { exclude: ['maplibre-gl'] },
```

否则 worker 会报 `Worker failed to load`。
